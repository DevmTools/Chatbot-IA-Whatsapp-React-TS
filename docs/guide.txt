1. Inicializar o projeto 

Crie um repositorio no Github
Crie uma pasta no computador
Dentro dela abra o cmd e inicie um repositorio
Configure o Repositorio:
 - git init
 - git branch -M develop
 - git remote add origin git@github.com:DevmTools/Chatbot-Watsapp-react-ts.git
 - Criar .gitignore: echo > .gitignore
 - Adicionar para commit: add .
 - Criar Commit: git commit -m "autualizando - primeiro commit"
 - Push para o Git: git push -u origin develop

2. Instalando Projeto + libs Backend

 Inicializar Projeto: npm init -y 
npm install express@^4 whatsapp-web.js qrcode ws 
npm install --save-dev typescript ts-node @types/express  @types/node @types/node-fetch @types/ws @types/qrcode

3. Criar o backend (em backend/server.ts) 

Copie seu backend/server.ts 

4. Criar o frontend (React + Vite + TS + CSS) 

npm create vite@latest frontend -- --template react-ts
cd frontend
npm install


6. Adicionar build do projeto + frontend

"scripts": {
  "build:frontend": "cd frontend && npm run build",
  "build:backend": "tsc",
  "build": "npm run build:frontend && npm run build:backend",
  "start": "node dist/server.js"
}

//Cria tcconfig.json
{
  "compilerOptions": {
    "target": "es2020",
    "module": "commonjs",
    "rootDir": "./backend",
    "outDir": "./dist",
    "strict": true,
    "esModuleInterop": true
  },
  "include": ["backend"], // ← Isso limita o build apenas à pasta backend
  "exclude": ["frontend", "node_modules"] // ← Isso garante não utilizar esses locais para o build do server
}

Rodar npm run build e conferir build na raiz e no frontend => ./dist


7. Servir React dentro do server.ts 

app.use(express.static(path.join(__dirname, "../frontend/dist")));

app.get("*", (_, res) => {
  res.sendFile(path.join(__dirname,
"../frontend/dist/index.html"));
});

8. Configurar empacotamento .exe com pkg 

Instalar globalmente npm install -g pkg

Adicionar configuração pkg no projeto package.json raiz
"bin": "dist/server.js",
"pkg": {
  "assets": [
    "frontend/dist/**/*"
  ]
}

Gerar a aplicação com executavel para windows .exe
npm run build
