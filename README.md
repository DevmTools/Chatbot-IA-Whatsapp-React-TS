
# Chatbot WhatsApp

Um chatbot para WhatsApp com backend em Node.js e TypeScript.

## Descrição
Este projeto implementa um chatbot para automação de mensagens + analise e conversação inteligente com IA generativa de terceiro, através de conexão de chave API(Esse modulo é opcional, o bot funciona com ou sem uma IA adicionada para auxiliar o atendimento) no WhatsApp, utilizando Node.js, TypeScript e Express para o backend.

## Tecnologias
- Node.js (^20.19.2)
- TypeScript
- Express (^4.x)
- React
- Vite
- WS(WebSocket)
- whatsapp-web.js

## Instalação e Execução
1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/chatbot-whatsapp.git
2. Instale as dependencias:
 - raiz do Projeto execute: 
    ```bash 
    npm i
    
 - Raiz pasta frontend execute: 
    ```bash
    npm i

3. Na raíz do projeto, execute: 
 - Buildar toda aplicação: 
    ```bash
    npm run build
    
 - Executar o Servidor
    ```bash
    npm run start
